# To-do List Expo

App To-do List em React Native com persistência local usando AsyncStorage.

## Como executar

1. Instale dependências:
   ```bash
   npm install
   ```
2. Inicie o Expo:
   ```bash
   npm start
   ```
3. Abra o app em um emulador ou dispositivo usando o Expo Go.

## O que foi atualizado

- Tarefas agora são salvas em `AsyncStorage`
- Tarefas são carregadas automaticamente ao iniciar o app
- O status de conclusão é mantido após reiniciar o aplicativo
